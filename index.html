RAG / LLMs

MultiDocRAG — Multimodal RAG for Technical Documents

End-to-end multimodal RAG pipeline for querying technical and normative documents (IEC / ITU-T standards, manuals). Extracts and indexes text, tables and figures from PDFs; hybrid dense + BM25 retrieval with query rewriting, figure/table matching and vision-QA on figures. Runs 100% locally (Ollama Mistral + Qwen2.5-VL, ChromaDB, BGE-M3) with no API keys, multilingual FR/EN/Arabic, Dockerized, and evaluated with RAGAS (faithfulness, answer relevancy, context precision/recall).

Agent-based LLM system powering a cross-platform mobile ordering assistant.
